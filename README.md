# تطبيق المحاكاة الصيدلانية والتثقيف الدوائي
منصة تفاعلية مخصصة للصيادلة للتدريب على الحالات السريرية الشائعة، فحص التداخلات الدوائية، وحساب الجرعات للأطفال.

## المميزات الرئيسية:
* 🔍 **فاحص التداخلات الدوائية والغذائية:** للتحقق من تفاعلات الأدوية والمستحضرات.
* 🎭 **المحاكاة السريرية:** سيناريوهات واقعية ومحاكاة لقرارات صيدلي المجتمع.
* 🧮 **حاسبة الجرعات:** حساب دقيق لجرعات الأطفال بناءً على الوزن ($mg/kg$).
